# Incident Management System - Backend

- Designed a **Spring Boot backend** for managing incidents with **JWT-based authentication** and **RESTful APIs**.
- Implemented features for **incident reporting, updates, and queries** by severity, date range, and ID.
- Utilized **MySQL** with **Hibernate/JPA** for database operations and documented APIs using **Swagger**.
- Built robust **error handling mechanisms** for validation and authentication issues.
- Technologies: **Java 21**, **Spring Boot 3**, **Hibernate**, **MySQL**, **Swagger**.
